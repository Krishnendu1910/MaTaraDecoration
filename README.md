✨ About the Project
Ma Tara Decoration is a work-in-progress website concept for an event decoration business based in Manushpur, Bandel, Hooghly, West Bengal. The page is designed to present event services and visual work in an elegant, gold-and-maroon themed layout.
🥂 Website Sections
- 🏠 Hero section with a prominent message and calls to action
- 🎉 Signature services covering weddings, rice ceremonies, birthdays, memorials, and other occasions
- ➕ Explore more services for additional event categories
- 💎 Why choose us section highlighting brand values and service qualities
- 💬 Testimonials section
- 🖼️ Event highlights gallery with an automatically moving image strip
- 🎥 Event video gallery
- 📅 Booking modal with a form that prepares an event enquiry in WhatsApp
- 📍 Contact section with location, map, phone, WhatsApp, working hours, and social links
- 🌙 Dark-mode toggle
- 📱 Responsive navigation with a mobile menu
- ✨ GSAP-powered hero and section reveal animations

🚀 Run Locally
No package installation is required for the current plain HTML, CSS, and JavaScript setup.
1. Clone the repository:
   git clone https://github.com/Krishnendu1910/MaTaraDecoration.git
   cd MaTaraDecoration
2. Start a local static server from the project folder. For example, with Python:
   python3 -m http.server 8000
3. Open http://localhost:8000 in your browser.
Opening index.html directly may work, but a local server provides a more consistent way to test the site and its media assets.

📌 Project Status
This project is in progress. Some displayed prices are placeholders, and the payment interface is explicitly a demo rather than a live payment integration. Confirm service details, pricing, contact destinations, and customer testimonials before treating the site as production-ready.
🔮 Possible Improvements
- Replace placeholder pricing with confirmed packages or enquiry-based pricing.
- Connect the booking flow to a validated enquiry backend or a clearly documented WhatsApp process.
- Replace the demo payment interaction with a secure, server-verified payment integration before accepting payments.
- Add form validation, accessibility checks, SEO metadata, and performance optimizations for large images and videos.
- Add a real customer-review source and obtain permission for testimonials and event photographs.
