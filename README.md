## ✨ About the Project

**Ma Tara Decoration** is a work-in-progress website for an event-decoration business based in **Manushpur, Bandel, Hooghly, West Bengal, India**.

The site combines a rich **maroon-and-gold visual identity**, event-service cards, animated page sections, photo and video galleries, and direct contact options. It is designed to help visitors explore decoration services and send event enquiries through WhatsApp.

## 💎 Features

- 🏠 **Immersive hero section** with calls to explore services or book a consultation
- 🧱 **Service cards** with imagery, event descriptions, and price labels
- ➕ **Explore More** interaction to expand or collapse additional services
- 🎞️ **Animated event gallery** with a continuously moving image strip
- 🎥 **Event video gallery** to showcase celebration highlights
- ✨ **GSAP animations** for the hero title and scroll-triggered section reveals
- 📱 **Responsive navigation** with a mobile side menu
- 🌙 **Dark-mode toggle** for an alternate visual theme
- 📝 **Booking modal** to collect name, phone number, and event details
- 💬 **WhatsApp enquiry flow** that creates a prefilled message from form details
- 📍 **Contact section** with map, phone, hours, and social links
- 💫 **Visual polish** including hover transitions, image zooms, and elevated cards

## 🚀 Run It Locally

This is a static **HTML + CSS + JavaScript** project. No Node.js package installation is required.

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Krishnendu1910/MaTaraDecoration.git
cd MaTaraDecoration
```

### 2️⃣ Start a local server

With Python 3 installed:

```bash
python3 -m http.server 8000
```

### 3️⃣ Open it in your browser

Go to **[http://localhost:8000](http://localhost:8000)**.

> 💡 Run the server from the project root so local image and video paths resolve correctly. GSAP and Google Fonts are loaded from external CDNs, so those features need an internet connection.
